How it works
1
Create a meeting — enter your name and a room name. You get a 6-letter code.
2
Share the code — copy it and send it to your team via any chat app.
3
Everyone joins — participants click "Join", enter the code and their name. No account needed.
4
Record if needed — hit the Record button to capture the meeting and download it as a .webm file.
Fully standalone — this entire app is a single HTML file. Host it on GitHub Pages, Netlify, or any static host. No backend required. Meetings connect peer-to-peer via WebRTC using PeerJS.
